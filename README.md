# 🌤️ Vatavaranam - Weather Web App

A sleek, modern, and responsive weather forecasting application built using vanilla web technologies. **Vatavaranam** allows users to instantly check live weather updates, temperatures, and atmospheric conditions for cities around the globe.

🌐 **[Live Demo Available Here](https://kaushik00101.github.io/Vatavaranam/)**

---

## ✨ Features

*   **Real-Time Weather Data:** Fetches live atmospheric metrics including temperature, humidity, and wind speeds via a weather API.
*   **Dynamic City Search:** Allows users to input any global city to get instant, localized weather updates.
*   **Responsive Dashboard:** Optimized with a mobile-first design, ensuring a seamless UI experience on smartphones, tablets, and desktops.
*   **Clean Visual Indicators:** Features contextual weather icons and clear typography for quick, at-a-glance reading.

---

## 🛠️ Tech Stack

*   **HTML5:** Structural layout for the weather search engine and data display dashboard.
*   **CSS3:** Modern styling, flexbox/grid layouts, and clean visual themes.
*   **JavaScript (ES6):** Asynchronous API fetching (`fetch`/`async-await`), dynamic DOM manipulation, and input event handling.
